# GoWild brand assets

GoWild uses a distinct multi-route terminal mark: three possible routes flow
into a prompt arrow and cursor. It represents the independent CLI, gateway, and
model choices that make up a launch route. It is not the mark of MindsHub,
MindsHub Cowork, or the imported source project.

The product palette is derived from the current MindsHub Cowork semantic design
tokens inspected on 21 August 2026, rather than estimated from screenshots.
GoWild maps those tokens onto its terminal UI as follows:

| Role | Dark | Light |
| --- | --- | --- |
| Background | `#080D18` | `#FAFAFA` |
| Surface | `#0E1626` | `#FFFFFF` |
| Active surface | `#131D31` | `#F4F4F4` |
| Selected surface | `#1A2640` | `#E5F4F7` |
| Primary text | `#F2F6FF` | `#0E0F10` |
| Accent | `#22D3EE` | `#1F9CB0` |
| Success | `#4ADE80` | `#15803D` |
| Warning | `#FBBF24` | `#B45309` |
| Danger | `#F87171` | `#B91C1C` |

The SVG is the editable source. `logo.png` is a 512×512 rendered copy for
surfaces that cannot display SVG. The terminal wordmark is `>_ gowild`, with the
prompt in the active theme accent.
